# Contributing to Pokemon Automation Codebase

Thanks for your interest in helping! This guide explains how to get help and send a change.

We welcome bug fixes, new programs and new features to existing programs.

## Getting Help

Ask questions on our [Discord server](https://discord.gg/cQ4gWxN). Discussion about the program is usually in #automation-chat and #automation-help channel.

## Sending a Pull Request

Due to the advance of AI technology, many Github repo maintainers are overwhelmed with AI generated PRs. We have the following policy as a response:
- If you use AI, you need to understand what the AI writes and can defend its decisions.
- When sending a pull request (PR), don't let AI generate a long description. Write your own PR description or edit an AI generated one. Keep it short, easy to read and on the point.
- Our devs work on the repo in their free time. To avoid overwhelming them, new contributors are advised to have at most two PRs at any time (draft and open PRs combined) and we prefer smaller PRs over bigger PRs.
- If you have more PRs or a big project that you are confident to present, talk to us in the [Discord server](https://discord.gg/cQ4gWxN) first. Once the devs are fine with reviewing you, you can disregard the previous bullet point.
